# ECMXS — English Commands Mixed System

**ECMXS** (short for English Commands Mixed System) is the main shell of the Zanop OSes — [Zanop Desktop OS](desktop-os.md), Zanop Mobile OS, and Zanop Television OS.

Instead of UNIX-style commands, ECMXS uses English-like commands, making the system easier to use for people who have never touched a terminal before.

- Repository: <https://github.com/Zanop-Technologies/english-commands-mixed-system>
- Language: C++
- License: AGPL-3.0

> Starting with the [v0.3 Chicago release](downloads.md), Zanop Desktop OS also gained POSIX compatible commands alongside ECMXS.
