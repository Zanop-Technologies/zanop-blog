The question of wheter Zanop OS will ever reach its 1.0 release has been raised, and it deserves a proper explanation.

If you don't know what Zanop OS is, it is a custom 64-bit kernel and operating system that has its own shell (ECMXS), its own GUI (Barks). It is currently developed by our wonderful developers, [Sir. Ezraieel](https://github.com/TheyCallMeEzraieel), [Sir. Hashes](https://github.com/hashesgenb65-dev), [Sir. Morimura](https://github.com/morimura07), and our lovely & no-nonsense founder, [Sir. John Adman](https://github.com/private09773).

## WIFI Management Interface
While our Management Interface for WIFI is still ongoing development, this was suggested by [Sir. Adam Naji](https://github.com/Zanop-Technologies/zanop-desktop-os/issues/12) to be added, as stated in his issue, it should require the following:
- Display a list of available Wi-Fi networks.
- Allow users to select a specific network to connect to.
- Support password-protected networks.
- Allow users to disconnect from the current network.
- Display connection status and signal strength.
- Support saving network credentials for automatic reconnection.
- Allow users to forget previously saved networks.
- Provide feedback for failed connections and authentication errors.
- Support refreshing the list of available networks.
- Integrate Wi-Fi controls into Zanop's system settings or network menu.

Which gives the goal of giving users full control of their wireless network connections.

## Web Browser
As suggested again by [Sir. Adam Naji](https://github.com/Zanop-Technologies/zanop-desktop-os/issues/10), Zanop OS will develop and integrate a fully functional web browser inside the OS, but currently, DHCP hasn't been developed yet and still in `docs/dhcp.md` on the Zanop Kernel. Our developers are currently developing support for these issues.

We will evaluate [Zen Browser](https://zen-browser.app) as a potential foundation for Zanop's main browser. Instead of developing a browser engine from scratch (suggested by Adam Naji), our developers including the founder will investigate on whether Zen can be adapted, forked, or rebranded to become Zanop's Default Browser.

## Conclusion
To answer the question about it being released after some updates: we are unsure on whether to release v1.0 yet.
