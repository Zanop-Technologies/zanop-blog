# Zanop Docs

Official documentation for **Zanop OS**, the operating system family built by [Zanop Technologies](https://zanop-technologies.cc.cd).

## What is Zanop OS?

Zanop Technologies was founded in 2022 by John Adman as a fictional operating system project — complete with imaginary products like the Zanop A Series phone. The idea eventually stopped being fiction and turned into working code.

Every Zanop product sits on the **Zanop Kernel**, written from scratch in C++ and targeting x86_64. Zanop OS is **not** a Linux distribution: it runs its own kernel, and it does not use UNIX commands — its main shell is ECMXS (English Commands Mixed System).
