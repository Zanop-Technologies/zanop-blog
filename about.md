# About Zanop

[Zanop Technologies](https://zanop-technologies.cc.cd) (also known as Zanop OS Technologies) was founded in 2022 by John Adman. It started as a planned **fictional operating system project** — made for fun, with imaginary products like the Zanop A Series phone, loosely modelled on Samsung's A Series. The idea eventually stopped being fiction and turned into working code.

> "An operating system that was supposed to be a joke, and then wasn't."

## The approach

A system should be built deliberately rather than stitched together from another project's components. Zanop OS is **not a Linux distribution** — it runs its own kernel, written line by line by people who wanted to find out whether they could write one.

Key principles:

- **Open source** — licensed under AGPL-3.0
- **Custom GUI** — built from scratch, not a desktop environment bolted onto an existing system
- **No UNIX commands** — the main shell is [ECMXS](ecmxs.md) (English Commands Mixed System)
- **One kernel, many systems** — the same kernel is intended to carry Desktop, Mobile, Television, and Server builds
