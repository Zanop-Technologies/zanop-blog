# Zanop Desktop OS

**Zanop Desktop OS** is the desktop build of Zanop OS — the first variant to reach public release, with the first Public Developer Release landing on **October 4, 2026**.

- Repository: <https://github.com/Zanop-Technologies/zanop-desktop-os>
- Language: C++
- License: AGPL-3.0
- Applications packaged as `.sft` files, powered by [Scriptsuft](scriptsuft.md)
- Shell: [ECMXS](ecmxs.md), with POSIX compatible commands added in v0.3

## Current release

**v0.3 Chicago** — see [Downloads & Releases](downloads.md) for the full version history.

## Requirements

- 2.5 GB of RAM
- 5–8 GB of storage

See [Getting Started](getting-started.md) to run it.
