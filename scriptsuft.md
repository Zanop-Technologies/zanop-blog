# Scriptsuft

**Scriptsuft** is the scripting/language for Zanop Desktop OS, Zanop Mobile OS, and Zanop Television OS.

Applications on Zanop Desktop OS are packaged as `.sft` files — Scriptsuft is the language that powers them.

- Repository: <https://github.com/Zanop-Technologies/scriptsuft>
- Language: Python (tooling/implementation)
