# Contributing

Thanks for your interest in contributing to Zanop OS!

## Ways to contribute

- **Found a bug?** Open an [issue](https://github.com/Zanop-Technologies/zanop-desktop-os/issues) on the relevant repository.
- **Have a feature idea?** [Start a discussion](https://github.com/Zanop-Technologies/discussions) on GitHub.
- **Want to write code?** Pick a repository and open a pull request.
