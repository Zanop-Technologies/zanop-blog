# Getting Started

Zanop Desktop OS is currently available as **Public Developer Release** builds — pre-release software, so expect bugs.

## Requirements

- 2.5 GB of RAM
- 5–8 GB of storage

## Download

Grab the latest build from the [releases page](https://github.com/Zanop-Technologies/zanop-desktop-os/releases). See [Downloads](downloads.md) for version history.

## Reporting bugs

If you encounter flickering, rendering issues, or anything else broken, please:

- [Open an issue](https://github.com/Zanop-Technologies/zanop-desktop-os/issues) on the repository, or
- Email us at <admin@zanop-technologies.cc.cd>

You can also [start a discussion](https://github.com/Zanop-Technologies/discussions) or chat on [Discord](https://discord.gg/bvBEHCnQv7).

## Building from source

The source lives at <https://github.com/Zanop-Technologies/zanop-desktop-os>. The OS and kernel are written in C++.
